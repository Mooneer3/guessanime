# Guessanime

Guessanime is a daily anime guessing game.

Players can test their anime knowledge through multiple game modes:

- Screenshot
- Character
- Opening
- Ending
- AniDle

Each day features a new set of challenges shared by all players.

## Tech Stack

### Frontend
- Next.js
- TypeScript

### Backend
- Java
- Spring Boot

### Database
- PostgreSQL

### Infrastructure
- Docker

### External APIs
- AniList
- Shikimori
